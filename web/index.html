Как это работает
  1. Диалог. Выберите язык и диалог — слева появится исходный транскрипт. Реплики бота и системы — только контекст, оценивается оператор.
  2. Чек-лист и кто оценивает. «OpenAI» — настоящая оценка ИИ (нужен ключ на сервере). «Повтор» — заново проверенный записанный ответ ИИ, только p1-ru-001 + чек-лист v5. «Тестовая заглушка» — проверка интерфейса без ИИ, только чек-листы v2/v3, итог всегда 0.00.
  3. «Оценить». Справа — итоговый балл, флаг грубой ошибки (08) и карточка по каждому критерию: ответ, вес, баллы, обоснование, цитаты. Кнопка-реплика подсвечивает место в транскрипте; при N/A указана причина.
  4. Не согласны? «Оспорить» на карточке → вкладка «История и апелляции»: комментарий, затем решение проверяющего и пересчитанный итог.
  5. «Чек-листы». Меняйте критерии (формулировку, вес, тип ответа, N/A, шкалу) и сохраняйте новую версию — она сразу применяется к следующей оценке.

Редактор чек-листа

Версии не меняются: отредактируйте, дайте новое имя версии и сохраните. Сохранённая версия сразу выбирается в поле «Чек-лист» на вкладке «Оценка». Официальная сдача (results.json) принимает только чек-лист организаторов (contact … critical) и откажет несовместимому.

Для продвинутых: весь чек-лист в JSON (вопросы, правила N/A и т. д.)

Форма выше редактирует этот JSON. Окончательно проверяет сервер: у шкалы должен быть уровень 0 и описания всех уровней, для N/A нужен вопрос применимости, у флага грубой ошибки нет веса.
