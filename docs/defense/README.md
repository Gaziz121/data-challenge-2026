# Защита CQA (демо на 5 минут)

| Файл | Что внутри |
|---|---|
| [JURY_SPEECH_RU.md](JURY_SPEECH_RU.md) | План выступления 1/2/1/1: что говорить, что нажимать, какие цифры увидит жюри, ответы на вопросы, запасной план, шпаргалка |
| [DEMO_RUNBOOK_RU.md](DEMO_RUNBOOK_RU.md) | Запуск, какие сочетания дают результат, ручная проверка шести функций ТЗ, типовые проблемы |
| [screenshots/](screenshots/) | 9 кадров по сценарию на синтетическом диалоге p1-ru-001 — запасной вариант, если живое демо не запустится |

**Запуск на Windows:** двойной клик `tools\demo\demo-start.cmd`. Перед защитой — `tools\demo\demo-reset.cmd`: очищает историю репетиций и спрашивает `YES`. Оба вызывают `tools\demo\run-demo.ps1`.

Нужен `.venv` с pydantic — см. раздел Windows в корневом README. Демо работает без интернета и без ключа OpenAI: используются повтор записанного ответа модели и тестовая заглушка.
