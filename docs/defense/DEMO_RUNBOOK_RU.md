# CQA — рунбук демо и ручной проверки (ветка main)

## 1. Запуск (PowerShell, из корня репозитория; или двойной клик tools\demo\demo-start.cmd)
```powershell
cd <папка репозитория>
powershell -ExecutionPolicy Bypass -File .\tools\demo\run-demo.ps1           # демо: 0 платных вызовов, откроет браузер
powershell -ExecutionPolicy Bypass -File .\tools\demo\run-demo.ps1 -Reset    # очистить историю и сохранённые версии (спросит YES)
powershell -ExecutionPolicy Bypass -File .\tools\demo\run-demo.ps1 -Live -EnvFile C:\путь\cqa.env   # настоящий OpenAI (платно)
```
- **Остановка:** Ctrl+C в окне сервера. Адрес: http://127.0.0.1:8765/.
- **Если интерфейс старый:** обновите страницу с Ctrl+F5.
- **`cqa.env` для живого режима:** одна строка `OPENAI_API_KEY=...`, файл вне репозитория. Лимит по умолчанию — 10 вызовов, около $0.013–0.023 за оценку.
- **`-WithApprovals`:** разрешает оценку трёх вымышленных вставленных диалогов. Без него вставленный диалог получает 403 — это сценарий «без разрешения».

## 2. Что даёт результат
| Кто оценивает | Чек-лист | Диалог | Результат |
|---|---|---|---|
| OpenAI — настоящая оценка ИИ | любой, включая вашу правку | любой из 60 синтетических DEV (`-Live`); новый вставленный — нужен grant с `--external openai` | реальная оценка |
| Повтор записанного ответа ИИ | только **v5** | только **p1-ru-001** | **100.00** |
| Тестовая заглушка (без ИИ) | v2 / v3 и их правки | любой DEV | **0.00** (проверка проводки) |
| Тестовая заглушка | v4–v7 | любой | отказ проверки — так задумано |

- **По умолчанию:** без ключа страница сама выбирает «Повтор» + v5 + p1-ru-001, первый клик «Оценить» даёт 100.00. С живым режимом выбирается OpenAI.
- **Неработающее сочетание:** жёлтая подсказка под панелью объясняет почему, рядом кнопка-исправление.

## 3. Ручная проверка по шести функциям ТЗ (реальные значения)
1. **Чек-лист** — вкладка «Чек-листы»:
   - «Исходная версия» = `…v3`, имя новой версии подставится само;
   - у критерия 07 доступны поля «Название», «Вес», «Тип ответа» (Да/Нет ↔ Числовая шкала), «N/A допускается», «Описание уровня 0/5/10», «Удалить критерий»; кнопка «Добавить критерий»;
   - «Сохранить как новую версию» → «Сохранено: … Версия выбрана в поле «Чек-лист»…» → «Оценить с этой версией →»;
   - ошибки: вес −5 → «проверьте: критерий 05 · вес»; дубль версии → «уже существует».
2. **Оценка** — вкладка «Оценка»: Язык → Диалог → Чек-лист → «Кто оценивает» → «Оценить». KZ/EN на заглушке: p1-kz-001 + v3, p1-en-001 + v2.
3. **Результат:**
   - блок «ИТОГОВЫЙ БАЛЛ 100.00», «Грубых нарушений нет · 08»;
   - карточки: «Да / Нет», «Базовый вес 10 → Итоговый вес 15.384615384615 · Баллы …», «вес перераспределён»;
   - кнопка «Реплика m0009 · №10» подсвечивает реплику;
   - C02/C03: «Причина N/A: …», «Проверенный участок разговора»;
   - «Скачать JSON оценки».
4. **Карточка из списка:** «История и апелляции» → «История оценок» → «Открыть» → вкладка «Оценка» с транскриптом и результатом.
5. **Апелляция:**
   - на карточке 07 «Оспорить» → «Какая оценка верна» = нет, «Ваше имя», «Комментарий» → «Подать апелляцию»;
   - в карточке апелляции: «Спорная оценка: Да · баллы 7.692307692308…», «Фрагмент диалога…», «Показать в транскрипте».
6. **Решение:**
   - «Имя проверяющего», «Ключ проверяющего» = `demo-reviewer-key`, «Изменить оценку» → нет, причина → «Сохранить решение»;
   - результат: «Исходный итог: 100.00 → Пересмотренный итог: 92.31»; на вкладке «Оценка» — «После апелляции: 92.31 … исходный итог 100.00 сохранён»;
   - вариант «Подтвердить исходную оценку» — итог не меняется.

## 5. Типовые проблемы
- **Красная «Проверка не пройдена» на заглушке** — выбран v4–v7. Нажмите «Взять 2026-11-07.v3» в жёлтой подсказке.
- **«Повтор есть только для записанной пары»** — нажмите «Перейти на p1-ru-001 + 2026-11-07.v5».
- **«OpenAI на этом сервере не настроен»** — перезапустите с `-Live -EnvFile …`.
- **«Оценка не выполнена · HTTP 403»** на вставленном диалоге — нет разрешения. Используйте `-WithApprovals` (только 3 вымышленных диалога).
- **«Локальный сервер CQA недоступен»** — сервер остановлен. Запустите лаунчер и обновите страницу.
- **Страница тёмная** — отключите тёмный режим или расширение для этого сайта (страница сама просит светлую тему).
- **Перед защитой** — запустите с `-Reset`, чтобы убрать следы репетиций.
